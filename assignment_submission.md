# Assignment Submission: Voice Translation Application (EN-FI)

## Project Overview
**SanaAI** is a real-time voice translation application designed to facilitate communication between **English** and **Finnish**. It leverages the Web Speech API for low-latency voice recognition and the MyMemory Translation API for accurate linguistic conversion.

### 🔗 Project Links
- **GitHub Repository**: [https://github.com/mahatodevi-arch/voice-translation-app-en-fi](https://github.com/mahatodevi-arch/voice-translation-app-en-fi)
- **Live Preview (Local)**: http://localhost:5173/

## Key Features
- **Real-Time Voice Sensing**: Instant transcription using `interimResults`.
- **Bi-Directional Support**: Seamlessly toggle between English and Finnish.
- **Video Subtitle Overlay**: Integrated video feed with live translated subtitles.
- **Premium UI/UX**: Modern glassmorphism design with responsive animations.
- **No-Key Translation**: Efficient translation using public API endpoints.

## Technology Stack
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Build Tool**: Vite
- **APIs**: Web Speech API, MyMemory API

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/mahatodevi-arch/voice-translation-app-en-fi.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
